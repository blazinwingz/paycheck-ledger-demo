# Security Policy

## Supported versions

This is a small demo with invented data. Only the latest version, the one on the
`main` branch and at https://blazinwingz.github.io/paycheck-ledger-demo/, gets fixes.

## How the app handles data

The app runs entirely in your browser. It has no server, sends nothing over the
network, and saves what you enter only in your own browser on your own device.
No figure in this repository describes a real person's pay.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Instead, use the
**Report a vulnerability** button on this repository's **Security** tab, which
sends your report privately.

This is a one-person hobby project, so replies are best effort. I'll aim to
respond within a week, and let you know whether I can fix it and roughly when.
